# Prepare ThystTV 1.4.0

## Goal

Prepare a reviewable 1.4.0 candidate from the merged October feature work:
Xtra feature ports (#30-#33), settings drag fix (#35), gesture guide in PiP (#36),
free pinch zoom (#37), spoiler-free VoDs (#38) and the closed-player leak fix (#39).
The second candidate adds the spoiler-free dialog fix (#42) and the half-folded
layout for foldables (#43).

## Non-goals

No new feature work, dependency changes, signing, tagging or publication in this
preparation step. README and site copy is a separate PR (#40).

## Current context

All ten PRs were merged into master on October 11 after green CI. The maintainer
tested the combined device-test debug build on a Honor Magic V5 and reported that
everything seemed fine; #39 came after that build. The maintainer chose version
1.4.0 and asked for Command Code (Muse Spark) as the adversarial reviewer because
GPT-5.6-sol/high (Codex CLI) is not available on this machine.

## Risks

Risk level: medium-high. The release includes player changes (live rewind, free
zoom, quality selection, spoiler-free progress hiding, keyboard listener), a Room
migration 35 -> 36 and a new Channel Points spend mutation. Debug testing does not
verify the signed upgrade path or the migration on an official install.

## Human approval

Required before implementation: no, for reversible release preparation requested
by the maintainer. The signed RC dispatch, tag creation and publication follow
`docs/RELEASE_PROCESS.md` and need the maintainer's device QA of the exact signed
RC APK first.

## Implementation steps

1. Merge the tested PRs in order with green CI.
2. Set version 1.4.0/code 14 and write the changelog, release notes, store
   changelog and bundled in-app changelog.
3. Run the branch release gate and record results.
4. Merge, freeze the RC SHA, dispatch the signed RC, run the review lanes and hand
   the exact signed APK to the maintainer for QA.
